APPEARANCE / 外观

挑一个顺眼的配色

主题只保存在本机。选中立刻生效，主界面、悬浮球和概览卡片会一起换色。

主题 JSON 怎么写？ 
{
  "name": "樱",
  "author": "你",
  "description": "四月的粉色",
  "scheme": "light",
  "glass": "dark",
  "vars": {
    "--bg": "#fdf3f5",
    "--surface": "#fffdfd",
    "--ink": "#2a2026",
    "--green": "#8b3f5a",
    "--green-dark": "#6d2f45",
    "--green-soft": "#fbe9ee",
    "--red": "#b52d3b",
    "--red-strong": "#8d1f2c",
    "--red-soft": "#fcecec",
    "--orange": "#bd650d",
    "--orange-strong": "#9d5308",
    "--orange-soft": "#fff2df"
  }
}

只写想改的变量即可，其余按 scheme 自动补默认值；glass 控制悬浮球浮层是深色还是浅色。 自定义主题保存在 %LOCALAPPDATA%\HomeworkDesk\data\themes.json。
